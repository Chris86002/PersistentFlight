# Contributing

Report bugs or suggest improvements through GitHub Issues. Include the release, game/dependency versions, reproduction steps, expected/actual result, and relevant log/debrief excerpts. Check the documented scope first and remove personal information from attachments.

For code changes, keep them focused, explain the resulting behavior, and state which checks you ran. Changes to orbital math need meaningful math cases; changes to flight ownership, persistence, time warp, or regional physics need native tests in a disposable KSP copy. Update user documentation when controls or limitations change. Do not commit game assemblies, private saves, local credentials, or test binaries.

See [development](docs/DEVELOPMENT.md) for builds and tests. Contributions are provided under the repository's GPL-3.0 license. No support response time is promised for this experimental project.
